## Primeiro Código em C

Este repositório contém meu primeiro código desenvolvido em **linguagem C**, como parte das atividades da faculdade de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto representa um dos meus primeiros contatos com a programação e tem como objetivo praticar conceitos básicos da linguagem C, como variáveis, entrada e saída de dados, operadores e estruturas de programação.

Este é o início da minha jornada no desenvolvimento de software e servirá como registro da minha evolução e aprendizado ao longo do curso.
